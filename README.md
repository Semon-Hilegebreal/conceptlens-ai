# ConceptLens AI 🎓✨

> Turn dense educational topics into interactive visual roadmaps, active recall quizzes, and Socratic AI tutoring.

Built for the **Prometheus July AI Challenge**.

---

## 🌟 Key Features

- **ELI5 & Core Pillars:** Deconstructs complex academic or technical topics into clear, structured breakdowns.
- **Interactive Visual Flowcharts:** Automatically generates real-time top-down diagrams powered by Mermaid.js.
- **Active Recall Micro-Quizzes:** Generates instant multiple-choice practice questions with detailed immediate feedback to solidify learning.
- **Socratic AI Tutor Panel:** Built-in interactive chatbot trained specifically to guide students through concepts without spoiling direct answers.

---

## 🛠 Tech Stack

- **Frontend:** Vanilla JavaScript, Tailwind CSS (via CDN), Mermaid.js
- **Backend:** Node.js, Express.js
- **AI Engine:** Google Gemini API (`gemini-2.5-flash` with Structured JSON Schema)
